# Knowledge Assistant (KA)
KA is a managed Agentic solution within the Agent Bricks portfolio that simplifies chatting to your documents. You can think of KA as a managed alternative to maintaining your own RAG system, depending on your use-case make an informed choice on what route to go here. Sample use-cases as shared in the docs include:

- Answer user questions based on product documentation.
- Answer employee questions related to HR policies.
- Answer customer inquiries based on support knowledge bases.

You can build and work with these through either UI or API.
